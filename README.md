# Yellow Daisy Bakery — HTML Website Project

A modern, responsive website concept for a fictional bakery brand. Created as a personal project to showcase front-end development skills.

## ✨ Features

- Mobile-friendly responsive design
- Multiple location sections (Paris, London, Istanbul)
- Catering menu layout
- Workshop registration page
- Contact form (static design only)

## 📄 Pages

- `index.html` – Main Pge
- `services.html` – Locations & Services
- `catering.html` – Catering Menu
- `workshop.html` – Workshop Info
- `about.html` – About Us
- `contact.html` – Contact Page

## 🛠 Technologies Used

- HTML5
- CSS3 (with CSS variables for theming)
- JavaScript (for basic interactivity)
- Flexbox & media queries for responsiveness

## 🚀 How to View

1. Clone or download the repository
2. Open `index.html` in your browser
3. No installation or dependencies required
